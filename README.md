# 📰 News Bangla 24

> A modern Bangla news platform built with Next.js, featuring category-based news, authentication, user profiles, and dynamic news details.

**Live Demo:** News Bangla 24 — https://news-bangla-24-one.vercel.app/

---

## 📌 About The Project

**News Bangla 24** is a modern Bangla news website built as a learning and practice project with **Next.js**.

The project focuses on building a real-world news platform with dynamic news content, category-based navigation, authentication, protected pages, user profiles, and a clean news-reading experience.

The project was developed step by step while learning and practicing modern full-stack web development concepts.

## 📰 News Features

The homepage includes different sections to provide a complete news browsing experience.

### News Categories

Users can browse news through category-based navigation.

### Latest News

A scrolling marquee displays the latest news headlines.

### Main News

The homepage highlights important news through a dedicated main news section.

### Most Read News

A separate section highlights popular news content.

### News Details

Users can click on news cards or links to open the corresponding detailed news page.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project

```bash
cd bangla-news-24
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

```text
http://localhost:3000
```
